# v0.4.0 - High frame rate (frame interpolation)

El port presenta ahora hasta el **refresco del monitor** (interpolando los frames de 30 Hz del
juego), en vez de quedarse a la tasa del juego. Menos latencia y movimiento notablemente más suave.

- **High frame rate (por defecto)**: `PresentEarly` + `Refresh Rate = Display` en RT64.
  Para volver al comportamiento anterior: `HH_REFRESH_RATE=original` y/o `HH_PRESENT_EARLY=0`.
- **Diagnóstico de rendimiento**: `HH_FPS=1` escribe los FPS en `hh.log`; `HH_DEVELOPER=1` habilita
  el **Inspector de RT64** (FPS/frametimes) que se abre con **F1**.
- **Atajos remapeados**: **F2** = aspecto (widescreen/4:3), **F3** = ventana, **F4** = MSAA;
  **F1** queda libre para el Inspector (con `HH_DEVELOPER=1`).
- **API gráfica** forzable con `HH_GRAPHICS_API=d3d12|vulkan|metal|auto`.

Parte de **v0.3.0** (widescreen con HUD/minimapa anclado, cursor oculto, carpeta `rom/`, README).

# v0.7.1 - Rendimiento: libultra delegada al runtime (más FPS)

Parche de **rendimiento** sobre v0.7.0. El port **recompilaba y ejecutaba como código del juego**
algunas funciones de **libultra** (control de interrupciones/TLB, caché y conversión/división de 64
bits) que están en caminos calientes. Ahora se **identifican por nombre y las sirve el runtime nativo**.

Efecto medido en Windows: subida fuerte de FPS (de ~80 de media a **144**, con bajadas ~80) **sin tocar
la lógica**, que sigue a **30 Hz** (`hh_tick.log`: 2 VI/tick). Sin cambios de jugabilidad: velocidad,
animaciones y audio normales.

## Qué cambia

- 11 funciones de libultra pasan de recompilarse a **delegarse al runtime**:
  `osSetIntMask`, `osUnmapTLBAll`, `osInvalICache`, `osInvalDCache`, `osWritebackDCache`,
  `osWritebackDCacheAll`, `osGetCount`, `__osSetFpcCsr`, `__ull_to_d`, `__ull_div`, `__ll_mul`.
  (`__ull_to_d` sola tenía 173 sitios de llamada.)
- El fondo del minimapa, el inventario, la interpolación de frames y el resto de features **no cambian**.

## Notas

- Es un arreglo de base: el binario se construye desde el `RecompiledFuncs` regenerado (repo de
  secretos de CI).
- No incluye cambios de API ni de configuración.

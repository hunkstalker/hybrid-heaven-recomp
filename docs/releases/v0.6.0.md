# v0.6.0 - Save system: 45-slot menu, save editor & extras

This release turns saving/loading and the in-game tooling into a full PC experience, unifies all
translations into a single editable source, and adds several quality-of-life options.

## Save & load

- **Custom save/load menu with 45 play slots** in a single `.pak` (up from 9). The file actually
  holds **74 records — 45 play slots + 29 internal save-point templates** — so the editor can rebuild
  a save at any checkpoint; only the 45 play slots are shown when loading. Layout/metadata: **ADR 0013**.
- **Real load from `CONTINUE`**, recreated **DATA LOAD / DATA SAVE** UI (1:1), **slot deletion**,
  the **difficulty letter** on the slot, and translated `AREA/LEVEL/TIME` rows.
- **`CONTINUE` is greyed out** when the `.pak` has no play data.
- **Automatic migration of older saves** (the previous 4-slot `.pak`): existing saves are preserved.
  Migration is **one-way** — there is no support for downgrading to an older build.

## Save editor (`EXTRAS > EDICIÓN DE PARTIDA`)

- Load/save any slot; edit **progress (Area-Part), level, skills, body, state, items and attributes**;
  **SIM. COMBATE** applies the exact in-game stat-growth formula; **RESTAURAR** and **ELIMINAR**.
- **Save-point templates** + **`IR A ÁREA`**: teleport to any Area-Part (loads a base template if no
  game is running).

## Extras (`EXTRAS`)

- **MODO HEAVEN** (global, persistent): ATTRS/STATE 99 + 86 skills, invulnerability (combat and
  field), non-consumable items and infinite POWER/STAMINA.
- **VENTAJA** (always advantage / back attack), **PODER ∞**, **RESISTENCIA ∞**, no field damage.

## Debug levels (`EXTRAS > DEBUG LEVELS`)

- Point-cycle to jump between scenes, with the `idx=` indicator: **F5/F6** = ±1, **Page Up/Page Down**
  = ±10 (area blocks), **Home** = index 0 (Area 1-0). Indices that hang are listed in
  `saves/skip_indices.txt` (editable without recompiling).

## Localization & presentation

- **Single translation source** (`assets/lang/*.txt`, key = English; **ADR 0014**), editable without
  recompiling. Accents and `¿¡` in the overlay messages; Japanese shown in **kana**.
- **Area title on load** (Work Sans SemiBold, translated `AREA` label, fade/hold transition);
  `DATA EDIT` removed from combat mode; `AREA/LEVEL/TIME` translated.

## Menu, audio & video

- **`SALIDA` (output)** as a stepper `MONO / STEREO / HEADPHONES`; **`ANTIALIASING`** as `< x >`.
- **Fullscreen ↔ window** transition fixed; port submenus centered; native **`DATA LOAD` fonts** used.

## Input

- **Start/Enter now enters menus** as well as A (title menu, port menus and the load/save UIs), as in
  the original. Vibration and saving are **decoupled**: **vibration works while saving/loading**
  (the game no longer thinks the Controller Pak is missing).
- **`MODO VS` disabled**: shown greyed-out in combat mode, the cursor can't land on it (needs a 2nd
  controller the port doesn't report yet).

## Notes

- The release build leaves **only `hh.log`**; every diagnostic dump is opt-in via `HH_*` variables.
- Dependencies: rt64 `a8f0a70`, N64ModernRuntime `a11fbf2`.
